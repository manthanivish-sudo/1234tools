How this works

  • Nothing you open is uploaded. A tool is JavaScript running in this tab: it reads the file you pick off your own disk and writes the result back there, so a client’s ledger or a class list never leaves the machine. The 49 AI tools are the exception, and each one shows you exactly what will be sent before it goes.
  • No account for the browser tools. 1,233 of the 1,282 ask for nothing at all — no sign-up, no email address, no trial with a date on it.
  • It keeps working with the network off, and it installs. Each tool is one page, and your browser keeps it once you have opened it — so it still runs on a train or a building site, and it can be added to a home screen like an app.
  • Where a rule can change, the page says when it was last checked. 21 tools apply a tax rate, a threshold or a statutory formula. Each one prints the date a person last checked it and links to the gov.uk, CBIC or board page that settles it, rather than asking to be trusted indefinitely.

  • Nothing is premium-only. There is no tool you cannot reach without paying. A paid plan raises the monthly allowance on the AI tools, and that is all it buys.
