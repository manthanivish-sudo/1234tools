Replacement skies for /ai-image/sky-replacement/
================================================

Six photographs and two generated skies. Every photograph is a Wikimedia Commons
file whose author released it under the Creative Commons CC0 1.0 Universal Public
Domain Dedication (https://creativecommons.org/publicdomain/zero/1.0/): no rights
reserved, no attribution required, commercial use allowed. The licence of each file
was read from the file's own Commons metadata (imageinfo.extmetadata: LicenseShortName,
LicenseUrl, AttributionRequired) on 2026-10-03 and is recorded below as the proof.
The only files chosen are ones their photographer uploaded as 'Own work' or dedicated
CC0 on Flickr themselves; nothing comes from a stock site's own licence.

Each was cropped to a sky-only 16:9 window, resized to 1600x900 with Lanczos and saved
as WebP quality 80 (Pillow). No other edit. The page loads one sky at a time, only when
it is chosen; the gallery buttons are CSS gradients, not thumbnails.
