What a batch of QR codes involves

A batch turns one list into many codes that share a look but carry different data. Each row is encoded on its own, so each code gets the version its content needs, even when all are printed at one size.

Format matters as much as length: a vCard spells out a field name on every line, while a MeCard packs name, phone and email into one.

How it works in your browser

The page parses the list, maps its columns and encodes each row with the single generator’s encoder and style controls.

  1. Tabs, commas or semicolons are detected from the first 20 lines, and quoted fields are handled.
  2. A first row is a header when at least half its cells name a field or a file-name column (name, label, filename, id, ref). One-field types without a header are read line by line, so commas in a URL survive.
  3. Each of up to 2,000 codes is decoded from its SVG at 10 and 4 pixels a module, then again on download from the exact PNG or SVG bytes, before the site’s ZIP writer stores it uncompressed.

Another worked example

A dental practice pastes three staff rows as contact cards under a header line, with an address for the practice manager only, at level M and 300 px PNG. The files are named amara-osei, tom-reid and lina-haddad, and all three verify. The address makes the longest content 271 characters, so versions run 9 to 12 and the smallest safe print is 37 mm wide; at level H, 13 to 17 and 47 mm wide. As MeCards with name, phone and email only, the same people need versions 4 to 5, at most 69 characters, and 23 mm wide.

Common uses

  • Conference badges Give each delegate a contact card from the registration export.
  • Asset tags Print a code for every laptop or tool ID in an inventory sheet.
  • School kits Label library books or classroom kits with their catalogue numbers.

Mistakes to avoid

  • Pasting contact cards without a header. Columns then follow field order, so a name, phone, email list puts the phone number in the last-name field.
  • Mixing content types without a type column. Without one, the type chosen at the top applies to every row.

More questions

Can I make QR codes from an Excel file?

Paste the copied cells, which arrive as tab-separated text, or save the sheet as CSV; .xlsx files are not read.

How do I number QR codes in sequence?

Fill ASSET-001 to ASSET-250 down a spreadsheet column and paste it; the tool encodes rows as given.

Why is the ZIP hardly smaller than the files?

The site’s ZIP writer stores files uncompressed, because PNG data is already compressed.

Privacy

Your list, your logo and every code made from them stay in this browser. Nothing is uploaded, the list is never stored, and the ZIP and the label sheet are assembled on your own device. Only your settings are remembered, here.

Tips

  • Paste straight out of a spreadsheet. Tabs, commas and semicolons are all understood, and a header line naming the columns is used if you give one. Change what any column is for under the codes.
  • Frame and label puts the same border and call to action — your brand, or “Scan for the menu” — round every code. A column called frame text gives each row its own label, such as Table 12, inside the same frame.
  • Add a column called name to choose the file names. Without one the file name comes from the content, which is fine for URLs and unhelpful for contact cards.
  • Every code is rasterised and read back, not just the first. Rows differ in length, so they differ in version, and a logo that clears a short URL can smother a long one.
  • A batch is only as printable as its densest code. The statistics give the smallest safe print width for the worst one in the run, which is the size the whole sheet should be set at.
  • For sticky labels, print one page of the label sheet PDF on plain paper with outlines on and hold it against a sheet of labels before using them: printers shift a page by a millimetre or two.
  • The download stays shut until every code has been checked, and each file is decoded once more from the exact bytes going into the archive. Anything that fails is left out rather than shipped.

Frequently asked questions

How many codes can I make at once?

Two thousand in one run. Everything happens in this tab — encoding, styling, checking and zipping — in short slices with a progress bar and a Cancel button, so the page stays responsive. For more than that, split the list and run it twice.

Can I use a CSV or a spreadsheet?

Yes. Paste it in or load the file. The separator is worked out for you, quoted fields are handled, and if the first row names the fields it is used as a header. Whatever mapping was worked out is printed above the codes, and each column’s job can be changed there, before you print four hundred labels.

Can one list mix links, Wi-Fi and contact cards?

Yes, with a column named type holding url, wifi, vcard and so on. Each row is then encoded as its own type, with its fields matched by the header names. A row with a type the tool does not know is listed with the reason rather than skipped.

Do all the codes have to look the same?

They share one shape, eye, gradient, logo and frame, so a sheet of table numbers or badges is consistent. A frame text column gives each code its own label inside that frame, and each framed code is read back as drawn, label included. A colour column and a background column (#rrggbb) give each row its own colours, and each such code is read back in them. For a one-off code with its own look, use the single QR Code Generator.

Can I print the codes on label sheets?

Yes. Label sheet (PDF) puts every code that passed the check on A4 or US Letter labels as vector artwork, with its name, a caption column or its content printed under it. Seven common grids are built in, and any other can be set in millimetres: columns, rows, label size, margins and gaps.

How do I know the whole batch will scan?

Twice over. Each code is drawn, rasterised and decoded again, and the result compared with the row it came from — once at a comfortable size and once small and rough. Then, when you press download, every file is decoded a second time from the exact bytes about to go into the archive, because a PNG at 300 px is not the same artefact as the SVG it came from. The download is shut until that finishes, and anything that fails to read is left out of the archive rather than shipped.

What happens to a code that will not scan?

It is marked in the grid, counted in the summary and excluded from the download, so the ZIP only ever contains codes that were decoded successfully. The buttons say how many passed, the page suggests the single change that would fix the batch — usually raising the error correction — and the CSV records every row including the rejected ones.

What names do the downloaded files get?

A column named name, label, filename, id or ref sets the file name. Failing that the name is made from the content itself, lower-cased and hyphenated, with duplicates numbered so nothing overwrites anything inside the ZIP.

Is any of this uploaded?

No. The list, the logo you choose, the codes and the ZIP are all built in your browser. Nothing is sent to a server, so a list of customer addresses or staff phone numbers never leaves the device. The settings are remembered in this browser; the list itself is not.
