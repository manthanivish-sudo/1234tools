JSON फ़ॉर्मैटर और वैलिडेटर

JSON को फ़ॉर्मैट, वैलिडेट और मिनिफ़ाई कीजिए। किसी भी सिंटैक्स गलती की सटीक लाइन और कॉलम बताता है।

  • मुफ़्त
  • कुछ भी अपलोड नहीं
  • आपके ब्राउज़र में चलता है

Use this tool in English

इस्तेमाल कैसे करें

  1. JSON पेस्ट कीजिए या फ़ाइल खोलिए।
  2. फ़ॉर्मैटेड, मिनिफ़ाइड, YAML, CSV या XML चुनिए।
  3. नतीजा कॉपी या डाउनलोड कीजिए।

प्राइवेसी

इस पेज पर सब कुछ आपके ब्राउज़र के अंदर चलता है। आप जो पेस्ट, टाइप या अपलोड करते हैं वह भेजा, लॉग या सेव नहीं होता।

काम की बातें

  • “ट्री” आउटपुट को खुलने-बंद होने वाले पेड़ की तरह दिखाता है; चुने हुए हिस्से का पाथ JSONPath बॉक्स में डाला जा सकता है।
  • $.items[?@.price > 10].sku जैसी JSONPath क्वेरी सिर्फ़ मेल खाने वाला हिस्सा रखती है।
  • “रिपेयर” JSON5, कमेंट और आखिरी कॉमा जैसी चीज़ें ठीक करता है, हर बदलाव की लिस्ट देता है, और तभी चलता है जब आप उसे टिक करें।
  • मिनिफ़ाइड आउटपुट भेजने के लिए है, फ़ॉर्मैटेड पढ़ने के लिए; दोनों एक जैसे पार्स होते हैं।

अक्सर पूछे जाने वाले सवाल

क्या मेरा डेटा कहीं भेजा जाता है?

नहीं। पार्स और फ़ॉर्मैट आपके ब्राउज़र के अपने JSON इंजन से होता है। कुछ भी पेज से बाहर नहीं जाता, इसलिए अंदरूनी होस्टनेम या की वाली कॉन्फ़िग फ़ाइलों के लिए भी यह सुरक्षित है।

आखिरी कॉमा से मेरा JSON फ़ेल क्यों होता है?

JSON के नियम में ऑब्जेक्ट या ऐरे के आखिरी आइटम के बाद कॉमा की इजाज़त नहीं, भले JavaScript में हो। उसे हटाइए, या “रिपेयर” टिक कीजिए — टूल उसे हटाकर बदली हुई लाइन दिखा देगा।

कितनी बड़ी फ़ाइल चल सकती है?

50 KB से बड़ी फ़ाइलें बैकग्राउंड वर्कर में चलती हैं, ताकि पेज अटके नहीं और देर हो तो “रद्द करें” बटन आए; 2 MB से बड़ी फ़ाइलें टेक्स्ट बॉक्स में नहीं दिखाई जातीं।
