# Share bar for every tool page — engineering spec

## 0. What the repo says that changes the baseline

| Baseline assumption | What the code shows | Consequence |
|---|---|---|
| `body` carries `data-sec` on every page | Only the 181 `.tool-io` pages (`pdf/`, `text/`, `ai/`, `image/`, …) have `<body data-sec="…">`. All 1,048 conversion pages, the hubs, `/for/`, `/guides/`, `/compare/` and the home page have a bare `<body>` | share.js must not read the section from `body`. build-share.js computes section and slug from the canonical at build time and writes them onto the placeholder (`data-share-sec`, `data-share-slug`) |
| `article.tool` has `data-tool` | True for 247 pages; the 1,048 conversion articles are `<article class="tool">` with no attribute; 14 `/learn/` pages are `<article class="tool">` with no `.calc`/`.tool-io` | Slug comes from the canonical, never from `data-tool`. `/learn/` pages get no row (no anchor matches) |
| `mountConverter` reads `?v=` | Correct; `from`/`to` are *not* read (`preset` only) | Add `?from=`/`?to=` reading, validated against `dimData.units` |
| `mountCurrency` reads nothing from the URL | Correct | Add `?amount=&from=&to=` validated against `MVRFx.COMMON` |
| QR generator is a plain IO tool | `mountQR` already has `shareLink()` (`?t=…&<fields>&style=…&v=1`), `applyShare()` and a "Copy share link" button, plus an `is-shared-view` mode on `<html>` | The share bar on `/qr/qr-code-generator/` reuses `shareLink()` for its params. Its `v=1` is the QR page's own flag and never collides with the converter's `?v=` (different pages) |
| `render-core.js` is on every page | It is on calculator/converter pages. IO pages load `render-dev.js`, `render-pdf.js`, `render-image.js`, `render-live.js`, `fx.bundle.js`, `aiimg-*.js`, each doing `window.MVRTool = window.MVRTool || {}` | The state hand-off must not depend on render-core: a `CustomEvent('mvr:result')` carrying the state in `detail`, plus `MVRTool.shareState()` as the "already happened" fallback, each engine writing both with a 3-line local helper |
| build-outbound tags outbound anchors in HTML | It rewrites `<a href="https://…">` in page source and bumps `sw.js` V | The share buttons are built at runtime, so build-outbound never sees them (no `utm_source=1234tools.com` on a WhatsApp intent). build-share.js bumps V itself when it writes |
| `make-og.js` writes one PNG | True; fonts base64-inlined, deterministic | Add a `--cards` mode; keep the site-wide PNG as the final fallback |
| X-Frame-Options | GitHub Pages sends none | `?embed=1` iframes work without any header change |
| `.cookies/` discloses storage keys | Lists `1234tools-theme` (plus consent/recent elsewhere) | share.js stores nothing; the figures toggle is per-page-load, off by default. No disclosure change |

Everything below assumes these corrections.

## 2. DOM

### 2.1 Placeholder (written by build-share.js)

```html
<!-- SHARE: generated by build-share.js, do not edit -->
<div class="share" data-share data-share-kind="calc" data-share-sec="finance" data-share-slug="compound-interest" hidden></div>
<!-- /SHARE -->
```

- `data-share-kind` ∈ `calc | converter | currency | code | qr | io | page`, decided from the page's inline mount call (see §8.2).
- `data-share-sec`: first path segment of the canonical (`finance`, `conversions`, `pdf`, `for`, `guides`, `compare`). This is `utm_campaign`, matching build-outbound's convention (≈20 values).
- `data-share-slug`: canonical path with the first segment and the slashes stripped: `compound-interest`, `length/angstrom-to-centimeter`, `accountants`. This is `utm_content` and the GA4 `item_id` suffix.
- `hidden` until share.js fills it, so a page without JS shows nothing half-built.

Position: for `calc` pages immediately after the `.calc` block (before `.tool-table`); for every `.tool-io` page immediately after `<div class="tool-io"…></div>`; for `article.collection` pages (`/for/*`, `/guides/*`, `/compare/*`) immediately before `</article>`.

## 4. The `shareState` contract

### 4.1 Shape

```js
{ params: { key: 'string', … },   // what goes in the query string; {} when nothing can be reproduced
  summary: 'Final Balance: £16,470.09' | null,   // ≤ 90 chars, primary output first
  changed: true | false,           // the figures on screen are not the worked example
  kind: 'calc' | 'converter' | 'currency' | 'code' | 'qr' }
```

`changed` = the visitor altered an input on this page **or** at least one value was taken from the URL (`fromLink`). It is separate from `touched`, which gates `mvr:tool-used` (the install offer) and must stay "visitor-made only".

### 4.2 Hand-off (identical 3 lines in every engine that announces)

```js
function announce(state) {
  (window.MVRTool = window.MVRTool || {}).shareState = function () { return state; };
  document.dispatchEvent(new CustomEvent('mvr:result', { detail: state }));
}
```

`MVRTool.shareState()` returns the latest state (for a share.js that boots after a mount); `mvr:result` reaches a share.js that booted before. share.js uses both. No engine imports share.js and share.js imports no engine.

### 4.3 Per mount

| Mount (file) | params | summary | changed | Edit |
|---|---|---|---|---|
| `MVRTool.mount` (render-core) | every `spec.inputs` key whose field value is non-empty, as its string value (dates as `YYYY-MM-DD`, selects as option value, text ≤ 200). All inputs, not only changed ones, so the link reproduces the figures even if a default changes later | see 4.4 | `touched \|\| fromLink` | yes |
| `mountConverter` (render-core) | `{ v, from, to }` | `"${fmt.number(v)} ${sym(from)} = ${fmt.number(convert(v,from,to,dim))} ${sym(to)}"` | `touched \|\| fromLink` | yes + read `from`/`to` |
| `mountCurrency` (fx.bundle) | `{ amount, from, to }` | `"${money(v,f)} = ${money(out,t)}"`, then `" · rate ${state.date}"` if it still fits in 90 | `touched \|\| fromLink`; null until rates loaded | yes + read `amount`/`from`/`to` |
| `mountCode` (render-dev) | `{ text }` when `0 < ta.value.length ≤ 300`, else `{}` | `null` (output may be long or private) | `touched \|\| fromLink` | yes |
| `mountQR` (render-dev) | `Object.fromEntries(new URL(shareLink()).searchParams)` (`t`, fields, `style`, `v=1`) | `null` | `applyShare()` returned true or any input/change event fired | yes (reuse `shareLink`) |
| `mountGenerate`, `mountFile`, `mountQRScanner`, `mountQRBulk`, `mountPDF`, `mountImage`, `mountTimezone`, `mountCountdown`, `mountStopwatch`, `mountCalculator`, `AIImg.mount`, AI-business mounts, Tool Finder | no announce → `null` → tool-only share | — | — | none |

Timezone/countdown/calculator read nothing from the URL today, so they are tool-only in this release. Phase-2 note (not in scope): countdown `?date=&time=&label=`, timezone `?date=&time=&from=&to=`, calculator `?expr=` ≤ 200 — each a ~10-line read plus one `announce` call under the same contract.

### 4.4 Calculator summary (`summaryOf(spec, results)`)

```js
function summaryOf(spec, res) {
  if (typeof spec.shareSummary === 'function') {
    try { const s = spec.shareSummary(res); if (s) return String(s).slice(0, 120); } catch (e) { /* fall through */ }
  }
  const cur = curFor(spec);
  const rows = spec.outputs
    .filter(o => res[o.key] !== undefined && !(o.format === 'text' && (res[o.key] === '' || res[o.key] === null)))
    .sort((a, b) => (b.primary ? 1 : 0) - (a.primary ? 1 : 0))
    .map(o => (o.label ? o.label + ': ' : '') + (fmt[o.format] || fmt.number)(res[o.key], o.unit, cur));
  if (!rows.length) return null;
  let s = rows[0];
  if (rows[1] && (s + ' · ' + rows[1]).length <= 90) s += ' · ' + rows[1];
  return s.length > 90 ? s.slice(0, 89) + '…' : s;
}
```

`spec.shareSummary(results)` is an optional per-tool hook for bespoke phrasing ("15% of 200 = 30"); no spec needs it to ship.

### 4.5 Exact render-core.js edits

1. `prefill(spec, form)` → returns the number of values applied (`let n = 0; … if (v !== null) { el.value = v; n++; } … return n;`). Returns 0 on the early exits.
2. Add `announce()` (4.2), `paramsOf(spec, form)` (reads `form.querySelector('[name=key]').value`, skips `''`/`null`), `summaryOf()` (4.4) inside the first IIFE.
3. `mount`: `const fromLink = prefill(spec, form) > 0;` then in `run()` after `renderResults(spec, res, out)`:
   `announce({ kind: 'calc', params: paramsOf(spec, form), summary: summaryOf(spec, res), changed: touched || fromLink });`
   In the `catch`, `announce({ kind: 'calc', params: {}, summary: null, changed: touched || fromLink })`.
4. `mountConverter`: after `asked` is read, read `from`/`to`:
   ```js
   let qf = null, qt = null;
   try { const q = new URLSearchParams(location.search); qf = q.get('from'); qt = q.get('to'); } catch (e) {}
   const has = k => k !== null && Object.prototype.hasOwnProperty.call(dimData.units, k);
   const fromLink = Number.isFinite(asked) || has(qf) || has(qt);
   form.appendChild(mk('from', 'From', has(qf) ? qf : (preset?.from || keys[0])));
   form.appendChild(mk('to',   'To',   has(qt) ? qt : (preset?.to   || keys[1])));
   ```
   `let touched = false;` set in `used()`. At the end of `run()` (after the table): `announce({ kind: 'converter', params: { v: String(v), from: f, to: t }, summary: \`${fmt.number(v)} ${dimData.units[f].symbol} = ${fmt.number(convert(v, f, t, dim))} ${dimData.units[t].symbol}\`, changed: touched || fromLink });` and when `v === null`: `announce({ kind:'converter', params:{}, summary:null, changed: touched || fromLink })`.
5. Expose `window.MVRTool.announceShare = announce;` (convenience; other engines keep their own copy).

### 4.6 fx.bundle.js edits

Before `load()`: read `?amount=` (finite number), `?from=`/`?to=` (must be keys of `COMMON`), set the controls, `fromLink` accordingly; `touched = true` in the four listeners. At the end of `paint()` (both the "no rates" and the normal path): `announce({ kind: 'currency', params: { amount: amount.value, from: f, to: t }, summary, changed: touched || fromLink })` with `summary` null when `!state.rates` or `v` invalid.

### 4.7 render-dev.js edits

`mountCode`: `let touched = false, fromLink = false;` (`fromLink = given !== null && given !== ''`); set `touched` in the three listeners; at the end of `run()`:
`announce({ kind: 'code', params: (ta.value && ta.value.length <= 300) ? { text: ta.value } : {}, summary: null, changed: touched || fromLink })`.
`mountQR`: after `render()` completes (where `renderStats` is called): `announce({ kind: 'qr', params: Object.fromEntries(new URL(shareLink()).searchParams), summary: null, changed: qrChanged })`, where `qrChanged` is set true by `applyShare()` returning true and by the `fieldHost`/`controls`/`typeSel` listeners.

## 5. share.js

### 5.1 Boot

```js
(function () {
  'use strict';
  const host = document.querySelector('[data-share]');
  if (!host) return;                                      // old cached page, or a page without a row
  const embed = document.documentElement.classList.contains('is-embed');
  const meta = readHead();                                // see 5.2
  if (embed) { embedMode(host, meta); return; }           // see 7
  const ui = build(host, meta);                           // DOM from §2.2, tool mode
  host.hidden = false;
  let state = null;
  const apply = (s) => { state = s || null; ui.update(state); };
  apply(window.MVRTool && typeof MVRTool.shareState === 'function' ? MVRTool.shareState() : null);
  document.addEventListener('mvr:result', (e) => apply(e.detail));
})();
```

Order of execution is deterministic: `share.js` is `defer` in the head, so it runs after parsing (the placeholder exists) and before `DOMContentLoaded`, which is when every page's inline script mounts the tool. The first `mvr:result` therefore always arrives after the listener is attached; the `shareState()` read covers any future page that mounts synchronously. No polling, no MutationObserver.

### 5.2 Page facts (`readHead()`)

- `title`: `article h1` text with the icon stripped (`h1.textContent.trim()`), falling back to `og:title` minus `" — Free Online | 1234Tools"`.
- `description`: `meta[name=description]`.
- `canonical`: `link[rel=canonical]` href (absolute, no query). Fallback `location.origin + location.pathname`.
- `sec`, `slug`, `kind` from the placeholder attributes.
- Never `location.search` (an installed app arrives with `?src=pwa`; a shared link arrives with figures and UTMs — none of that must be re-shared).

### 5.3 URL building

```js
function url(channel, withFigures) {
  const u = new URL(meta.canonical);
  if (withFigures && state) for (const [k, v] of Object.entries(state.params)) u.searchParams.set(k, v);
  u.searchParams.set('utm_source', channel);
  u.searchParams.set('utm_medium', 'share');
  u.searchParams.set('utm_campaign', meta.sec);
  u.searchParams.set('utm_content', meta.slug);
  return u.href;
}
```

Channels: `whatsapp telegram x facebook linkedin reddit email copy native qr embed card` (`card` added to the baseline list for the result card's QR). Tool params come first so a receiver reading the address bar sees the figures before the tracking. The page's `prefill()` ignores every key it does not declare, so `utm_*` never reaches a field.

### 5.4 Text templates

Let `T` = title, `D` = description, `S` = summary, `F` = toggle checked (and `state.summary || params` non-empty), `U(ch)` = `url(ch, F)`.

- `text` = `F && S ? \`${S} — ${T}, free on 1234Tools\` : \`${T} — ${D}\`` (description clipped to 160 at a word boundary).
- WhatsApp: `https://wa.me/?text=${enc(text + '\n' + U('whatsapp'))}`
- Telegram: `https://t.me/share/url?url=${enc(U('telegram'))}&text=${enc(text)}`
- X: `https://x.com/intent/post?text=${enc(fit(text, 256))}&url=${enc(U('x'))}` — URLs count as 23 on X; `fit()` cuts at a word boundary and appends `…`, so text + space + URL ≤ 280.
- Facebook: `https://www.facebook.com/sharer/sharer.php?u=${enc(U('facebook'))}` (the `quote` parameter is ignored by Facebook since 2017; the OG card and og:description carry the message; with figures on, Facebook scrapes the figures URL and shows the tool-level card).
- LinkedIn: `https://www.linkedin.com/sharing/share-offsite/?url=${enc(U('linkedin'))}` (text not accepted; OG does the talking).
- Reddit: `https://www.reddit.com/submit?url=${enc(U('reddit'))}&title=${enc(F && S ? \`${S} — ${T}\` : \`${T} (free, runs in your browser)\`)}`
- Email: `mailto:?subject=${enc(T + ' — 1234Tools')}&body=${enc(text + '\n\n' + U('email'))}`
- Copy link: writes `U('copy')` only (a URL, nothing else, so it pastes cleanly into a chat).
- Native: `navigator.share({ title: T, text, url: U('native') })`; `AbortError` is silent.
- QR popover: encodes `U('qr')`.
- Embed snippet (`calc`, `converter`, `currency` only):
  ```html
  <iframe src="https://www.1234tools.com/finance/compound-interest/?embed=1&utm_source=embed&utm_medium=share&utm_campaign=finance&utm_content=compound-interest" width="100%" height="640" style="border:0;border-radius:12px;max-width:720px" loading="lazy" title="Compound Interest Calculator — 1234Tools"></iframe>
  <p style="font:14px system-ui"><a href="https://www.1234tools.com/finance/compound-interest/">Compound Interest Calculator</a> by 1234Tools — free, runs in the browser.</p>
  ```
  `embed=1` is set first; figures params ride along when the toggle is on. Height 640 (`calc`), 560 (`converter`), 600 (`currency`). The `<p>` is the backlink that survives even when the iframe is stripped.

All anchors have `target="_blank" rel="noopener"` except `mailto:`. hrefs are rebuilt on every `mvr:result`, on toggle change and on `Prefs` change (which re-announces through `run()`).

### 5.5 Toggle behaviour

- Rendered hidden; shown when `state.changed && (state.summary || Object.keys(state.params).length)`.
- Unchecked by default on every page load; never stored.
- Label by kind: "Include my figures" (`calc`, `converter`, `currency`), "Include my text" (`code`), "Include this code's content" (`qr`).
- When checked: `.share-result` shows `Sharing: <strong>${S}</strong>` (or `Sharing the link with what you entered` when `S` is null) and all hrefs switch to `url(ch, true)`.

### 5.6 Copy

`copyText(t)`: `navigator.clipboard.writeText` inside the click handler; on failure a hidden readonly `<textarea>` + `document.execCommand('copy')` (the `aiimg-share.js` pattern, duplicated rather than imported). Feedback: button gets `.is-done` and its label reads "Copied" for 1.5 s; `.share-status` (`role=status`) says "Link copied" / "Could not copy — select the address bar instead".

### 5.7 Lazy QR

First click on QR: inject `<script src="/engine/qr.bundle.js">`, await `load` (the SW caches it cache-first thereafter), then `const qr = QR.encode(U('qr'), 'M'); pop.innerHTML = QR.toSVG(qr, { scale: 6, quiet: 4, dark: '#06080f', light: '#ffffff' })` — `toSVG` returns an SVG string the engine itself produced (trusted). Under it a `.share-url` line with the URL and a "Download SVG" link (`data:image/svg+xml;charset=utf-8,` + encoded string, `download="<slug>-link.svg"`). The popover is a `role=dialog`; Escape or Close hides it and returns focus to the QR button; `aria-expanded` mirrors it. If the script fails to load: status "Could not load the QR engine" and the URL line alone.

## 6. Embed mode

- URL flag `?embed=1`. build-share.js writes a 1-line inline script in the head block (synchronous, before `<body>` parses, so there is no flash of header):
  `<script>if(/[?&]embed=1(?:&|$)/.test(location.search))document.documentElement.classList.add('is-embed');</script>`
- CSS (`D1-share`) hides header, sidebar, sidebar button, Find FAB, crumbs, footer, scrim, consent bar, eyebrow, lede, panels, privacy line and the share row itself; `.tool-results` loses `sticky`.
- share.js `embedMode()`: appends after `.calc` (or `.tool-io`) a `<p class="embed-credit">Powered by <a href="${url('embed-credit', false)}" target="_blank" rel="noopener">1234Tools</a><a href="${url('embed-open', false)}" target="_blank" rel="noopener">Open the full tool ↗</a></p>`; delegates clicks so every `<a>` without a target opens in a new tab (the `cur-note` settings link, for instance) — the host page keeps the frame.
- `analytics.js`, directly after `if (!GA4 && !CLARITY) return;`: `if (/[?&]embed=1(?:&|$)/.test(location.search)) return;` — no banner, no GA4, no Clarity inside third-party frames (third-party cookie context; nothing to consent to).
- `pwa.js`, at the top of its IIFE: `if (document.documentElement.classList.contains('is-embed')) return;` — no install offer in a frame.
- The service worker still registers (harmless; the host site's origin is different and gets nothing).
- Hubs, collections and the home page have no `[data-share]`, so `?embed=1` on them only hides the shell; acceptable, not advertised.
