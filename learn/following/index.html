Following the Field

Where to read the news yourself, rather than a snapshot that is stale by Tuesday.

Where to start

This is a list of places to follow, not a news page. A static site cannot carry headlines honestly — they are stale within days and the page starts lying about how current it is. Pick two or three and subscribe. The primary sources at the top of each group announce things first; everything else is commentary on them.
