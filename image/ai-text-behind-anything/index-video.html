Tips

  • Use a clear photo where the main subject is reasonably separated from the background for better object selection.
  • For a cyclist, select both the person and bicycle when you want the text to appear behind the entire subject.
  • For several people, use Behind People to select all detected people at once.
  • You can select individual objects if you want text behind one subject but in front of another.
  • Large images can require more browser memory and processing time. The editor scales very large images to a practical working resolution while preserving the original aspect ratio.

Frequently asked questions

Does the AI upload my photo?

No. The image is supplied directly to the browser-side editor. The segmentation operation is performed locally in your browser rather than by a 1234Tools image-processing server.

Can I put text behind a person and bicycle?

Yes. Select the detected person and bicycle. The editor combines their masks and places the text underneath those selected objects.

Can I put text behind multiple people?

Yes. Select multiple people or use the Behind People preset.

Can I download the finished image?

Yes. Export the result as PNG, JPEG or WebP.

Do I need to install software?

No. The tool runs in a modern browser. The AI model may be downloaded the first time it is used.
