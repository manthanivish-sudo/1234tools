Tambola Ticket Generator

Make valid Tambola (Housie) tickets in strips of six that use every number 1–90 once. Print 6 or 12 a page on A4 or Letter, download a PDF, or send each ticket as a picture on WhatsApp. Free, no sign-up.

Privacy

Tickets are made by your own browser from the set code; nothing is uploaded, and because the same code always makes the same tickets, no list of tickets is stored anywhere. The PDF and the pictures are made on this device. Your settings and the last set code you printed are remembered on this device only.

How it works

  1. Choose how many tickets (in strips of six), a title for the top of each ticket and a colour.
  2. Keep the fresh set code, or type one you used before to make the very same tickets again.
  3. Press Print (A4 or US Letter, 6 or 12 tickets a page, with cut lines) or Download PDF — or make ticket pictures to send on WhatsApp.
  4. Open the caller for this set: it rebuilds any ticket from the number printed on it, so claims are checked in seconds.

Where people use it

  • Diwali at home — a strip of six for every family, printed on A4 and cut along the dashed lines
  • Kitty party — twelve tickets a page, titled with the host’s name and the date
  • Video call — each player gets their ticket picture on WhatsApp and marks it on paper or on screen

Tips

  • For 20 players make 24 tickets (four strips of six): everyone gets one and a few can play two.
  • A strip of six uses every number from 1 to 90 exactly once, so each number called is on one ticket of every strip.
  • Every ticket has 15 numbers, five in each row, and each column keeps its own range: 1–9, 10–19 and so on up to 80–90 in the last column, sorted top to bottom.
  • The set code and the ticket number are printed on every ticket (K7MPQ2-014). Type the same code into Set code to reprint exactly the same tickets, or a ticket number into the caller to check a claim.
  • Ticket pictures are PNG images, one per ticket, sized to read on a phone. Download one at a time — or share it straight to WhatsApp on phones that allow it — or all of them together in a ZIP.
  • Show on TV puts the first strip on the big screen — handy on a video call for showing new players how to read a ticket.
  • The PDF uses the standard PDF fonts, which cannot draw Hindi or other non-Latin letters; for a title in Hindi use Print, which uses your browser’s own fonts.

Frequently asked questions

How many tickets do I need for 20 people?

One each plus a few spare: 24 tickets, which is four strips of six, prints on four A4 pages at six a page or two pages at twelve. Tickets are always made in whole strips of six.

Are these real Tambola tickets?

Yes. Each ticket has three rows and nine columns with 15 numbers, five in every row; the first column holds 1–9, the next 10–19 and so on, with 80–90 in the last; every column has one to three numbers, sorted top to bottom; and each strip of six uses every number 1–90 once. Our tests check 10,000 strips against those rules.

Can I reprint the same tickets?

Yes. Every ticket shows its set code. Type that code into Set code with the same number of tickets and you get exactly the same tickets, in any browser. The last code you printed is also offered on this device.

What does Early Five mean?

Early Five is won by the first player to mark any five numbers on their ticket. The other usual prizes are the Top, Middle and Bottom lines, Four Corners (the first and last numbers of the top and bottom rows) and Full House, all fifteen.

How do I play on a video call?

Make the tickets here and press Ticket pictures: send each player their picture on WhatsApp. Open the Tambola Number Caller with the same set code, share its big-screen window in the call, and when a player claims, type their ticket number into Check a claim.

Do I have to keep a list of who has which ticket?

No. The ticket number is enough: the caller rebuilds the ticket from it and checks the claim against the numbers called. Writing names next to numbers is only needed if you want to know who has which ticket before they claim.

Is this the same as 90-ball bingo?

Yes. Tambola, Housie and UK 90-ball bingo use the same tickets: three rows, nine columns, fifteen numbers, six to a strip. Only the prize names differ; the caller can check One line and Two lines as well.

Is anything uploaded?

No. The tickets, the PDF and the pictures are all made by your browser on this device, and nothing is sent anywhere.
